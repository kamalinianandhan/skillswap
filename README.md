# SkillSwap – Peer-to-Peer Skill Exchange Platform

SkillSwap is a Java-based application designed to connect people who want to learn new skills with people who are willing to teach them. It helps learners find suitable skill providers based on their interests and hourly rates.

## Features
- Search for available skills.
- Find matching skill providers.
- Identify the lowest-cost provider.
- Schedule learning sessions.
- Calculate session costs.
- Save session details to a file.
- Graphical user interface using Java Swing.
